## 🧠 What is RAG?

Traditional search returns keyword matches. **RAG goes further:**

1. **Retrieve** — Find the most semantically relevant documents using vector embeddings
2. **Augment** — Inject those documents as context into a prompt
3. **Generate** — Let an LLM produce a precise, grounded answer

This mirrors how enterprise AI systems like **SAP Joule** work under the hood.
